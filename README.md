Learn HTML-Form
1) Pengenalan HTML Form
2) Form Tag (yang dimana terdapat banyak attribute di dalam Tag Form seperti name, action, enctype, method, target, dll.)
3) Input Tag (Membuat input di dalam sebuah form menggunakan tag input)
4) Input Text (Salah satu attribute type dari tag input)
5) Label Tag (Membuat label agar ketika menekan tulisan diatas form input atau judul dari form input tersebut, bisa langsung menuju ke kolom input tersebut)
6) Input Submit (Salah satu attriibute type dari tag input yang berfungsi untuk mengirimkan data yang dimasukkan oleh pengguna web melalui Form yang tersedia)
7) Memproses Input (Menggunakan attribute action pada tag form untuk menentukan tujuan dari data yang telah dimasukkan pada kolom input dan method get pada tag form untuk menerima input data dari kolom input di URL browser)
8) Input Reset (Salah satu attribute type dari tag input, berfungsi untuk mereset nilai yang terdapat di setiap kolom dalam form kembali ke nilai defaultnya)
9) Input Button (Salah satu attribute type dari tag input, berfungsi untuk berinteraksi dengan kode seperti JavaScript, dll.)
10) Input Checkbox (Salah satu attribute type dari tag input, berfungsi untuk menerima input data lebih dari satu, namun inputnya sudah disesuaikan)
11) Input Color (Salah satu attribute type dari tag input, berfungsi untuk menerima input data tipe warna dalam bentuk hex code)
12) Input Date (Salah satu attribute type dari tag input, berfungsi untuk menerima input data tipe tanggal dengan format yyyy-mm-dd, serta attribute min dan max untuk membatasi tanggal yang akan dipilih)
13) Input Date Time (Salah satu attribute type dari tag input, berfungsi untuk menerima input data tipe tanggal dengan format yyyy-mm-ddThh:mm, serta attribute min dan max untuk membatasi waktu yang akan dipilih)
14) Input Month (Salah satu attribute type dari tag input, berfungsi untuk menerima input data tipe tahun dan bulan dengan format yyyy-mm, serta attribute min dan max untuk membatasi waktu yang akan dipilih)
15) Input Time (Salah satu attribute type dari tag input, berfungsi untuk menerima input data tipe jam dan menit dengan format hh:mm, serta attribute min dan max untuk membatasi waktu yang akan dipilih)
16) Input Week (Salah satu attribute type dari tag input, berfungsi untuk menerima input data tipe minggu dalam satu tahun dengan format yyyy-Www, serta attribute min dan max untuk membatasi waktu yang akan dipilih)
17) Input Email (Salah satu attribute type dari tag input, berfungsi untuk menerima input data dengan format email)
18) Input File (Salah satu attribute type dari tag input, berfungsi untuk menerima input data dengan tipe file, serta menggunakan method "POST" dan enctype multipart/form-data agar form dapat mengirim berkas filenya)
19) Input Hidden (Salah satu attribute type dari tag input, berfungsi untuk menerima input data yang dimana data tersebut tidak terlihat oleh si pengguna web. Semisal dalam kasus mengirim userId untuk database yang memang hal tersebut tidak perlu diketahui oleh pengguna webnya)
20) Input Image (Salah satu attribute type dari tag input, berfungsi bukan digunakan untuk input berupa berkas gambar, melainkan digunakan untuk membuat tombol submit namun berupa gambar. Intinya, input image merubah tombol submitnya menjadi image, bukan teks)
21) Input Number (Salah satu attribute type dari tag input, berfungsi untuk menerima input data berupa number atau angka, serta attribute min dan max untuk membatasi nilai yang akan dipilih)
22) Input Password (Salah satu attribute dari tag input, berfungsi untuk menerima input data berupa password, yang dimana pada input type password tersebut karakter yang terdapat dalam kolom akan di masking atau tidak ditampilkan karena bersifat rahasia)
23) Input Radio (Salah satu attribute dari tag input, berfungsi untuk menerima salah satu pilihan data. Serupa dengan checkbox, namun pada checkbox kita dapat memilih semua data, sedangkan pada radio hanya dapat memilih salah satu saja dari data yang disediakan)
24) Input Range (Salah satu attribute dari tag input, berfungsi untuk menerima input data berupa number / angka yang ditentukan jangkauan minimal dan maksimalnya, serupa dengan input number namun yang membedakan adalah komponen inputnya dalam bentuk slider, serta attribute step untuk mengubah nilai naik dan turunnya)
25) Input Telephone atau Input Tel (Salah satu attribute dari tag input, berfungsi untuk menerima input data tipe informasi dengan format nomor telepon)
26) Input URL (Salahh satu attribute type dari tag input, berfungsi untuk menerima input data tipe URL)
27) Text Area Tag (tag yang berfungsi untuk input data tipe text yang multi baris, serta attribute cols untuk menentukan panjang input dan attribute rows untuk menentukan tinggi input)
28) Button Tag ( tag yang berfungsi untuk membuat tombol, serupa dengan input type button, namun yang membedakan adalah pada button tag kita dapat bebas menambahkan isi dari button kayak seperti teks atau gambar)
29) Select Tag (tag yang berfungsi sebagai alternatif lain jika opsi pilihan data terlalu banyak, yang dimana didalam select tag terdapat attribute seperti type text, namun kita dapat memilih opsi lain seperti type radio, dll.)
30) Data List Tag (tag yang berfungsi untuk menambahkan sumber data yang dapat dijadikan sebagai rekomendasi input value,serta autocomplete, semacam rekomendasi di search bar Google)
31) Field Set Tag (tag yang berfungsi untuk membungkus / grouping beberapa input sehingga lebih mudah untuk dimengerti ketika dilihat oleh si pengguna web, serta legend tag yang berefungsi untuk menambahkan informasi berupa deskripsi / caption group saat menggunakan fieldset tag)
