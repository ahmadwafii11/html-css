Learn CSS-Layout
1) Pengenalan
2) Membuat Folder Project
3) Normal Flow (Normal flow merupakan bagaimana Web Browser menampilkan tata letak halaman HTML secara default, ketika kita tidak mengubah apapun pada tata letaknya. Intinya Web Browser hanya menampilkan komponen HTML secara normal, tanpa adanya letak khusus pada setiap komponen HTMLnya.)
4) Display (Mengetahui nilai atau value pada attribute Display dalam CSS seperti inline, block, inline-block dan none.)
5) Flexbox (Flexbox merupakan sebuah nilai dari properties display yang berbentuk kotak. Pada flexbox, terdapat beberapa nilai lain seperti flex container, flex item dll. Selain itu, terdapat beberapa attribute untuk mengubah style dari Flexbox seperti flex-direction (Untuk mengubah tampilan default Flex Item yang dari kiri ke kanan), flex-wrap (Untuk merubah default Flex Item yang ditampilkan dalam satu garis, baik itu vertikal (row) atau horizontal).)
6) Flexbox Items (Flex Item merupakan komponen anakan langsung dari si induk Flex Container. Terdapat beberapa attribute yang dapat digunakan untuk mengubah style Flex Items seperti attribute order untuk mengubah urutan komponen ditampilkannya HTML, attribute flex-grow untuk mendefinisikan kemampuan membagi area pada flex item untuk berkembang jika diperlukan, attribute flex-basis digunakan untuk membagi area pada Flex Item dengan mengambil ruang sebesar minimal yang ditentukan dan jika tidak terdapat ruangan yang tersedia maka akan mengambil ruang semampunya.)
7) Flex Alignment (Menggunakan beberapa attribute untuk menyelaraskan Flex Item yang terdapat di dalam Flex Container seperti attribute justify-content (untuk menentukan bagaimana Web Browser menentukan jarak antar Flex Item), attribute align-items yang dapat digunakan untuk perataan Flex Item secara cross-axis (kolom Y pada Flex Item), attribute align-content yang serupa dengan attribute justify-content namun dapat digunakan hanya jika menggunakan attribute flex-wrap dengan value atau nilai wrap / wrap-reverse, attribute gap, row-gap dan column-gap sebagai pengganti margin untuk menentukan jarak dalam baris (row) atau kolom (column) saat menggunakan Flexbox.)
8) Grids (Grid Layout merupakan fitur CSS yang dibuat untuk mengatasi permasalahan tata letak yang kompleks.Grid Layout sistem tata letak yang berbasis dua dimensi. Bentuk dari Grid itu serupa dengan tabel. Untuk membuat Grid Container, kita dapat menggunakan attribute display dengan nilai grid.)
9) Grid Terminology (Beberapa istilah kata mengenai Grid. Seperti Grid Container, Grid Item, Grid Line, Grid Cell, Grid Track dan Grid Area.)
10) Grid Template (Grid Template digunakan untuk menentukan kolom dan baris dalam Grid. Terdapat attribute seperti grid-template-columns yang digunakan untuk menentukan kolom, attribute grid-template-rows digunakan untuk menentukan baris.)
11) Grid Items (Membahas mengenai Grid Item yang dapat kita lakukan seperti attribute grid-column-start Untuk menentukan letak grid dimulai dari garis atau line kolom mana, attribute grid-column-end Untuk menentukan letak grid diakhiri dari garis atau line kolom mana, attribute grid-row-start Untuk menentukan letak grid dimulai dari garis atau line baris mana, attribute grid-row-end Untuk menentukan letak grid diakhiri dari garis atau line baris mana, [namaline] untuk menentukan nama dari grid line, attribute grid-template-areas Untuk membuat Grid Area, attribute grid-area untuk menentukan Grid Item muncul diarea mana.)
12) Grid Alignment (Serupa dengan Flexbox Alignment, namun pada Grid Alignment dapatmemilih antara menyelaraskan seluruh isi konten pada Grid Cell (sama seperti Flexbox Alignment) atau hanya untuk satu Grid Cell. Adapun attribute nya juga mirip" dengan Flex Alignment seperti justify-content, align-content, justify-items, align-items, justify-self, align-self, gap. )
13) Subgrid (Menggunakan attribute grid-template-columns dan grid-template-rows dengan nilai value subgrid agar dapat menyelaraskan apabila terjadi perubahan pada kedua attribute tersebut di grid container.)
14) Multiple Column (Multiple Column layout merupakan cara untuk membuat tata letak seperti kolom dalam koran. Terdapat beberapa attribute didalamnya seperti attribute column-count untuk membuat column, attribute column-width untuk menentukan lebar kolom, tanpa peduli jumlah kolom yang akan dibuat, Attribute column-rule untuk mengatur border dari Column, Attribute columm-gap untuk mengatur jarak Column.)
15) Float (Attribute float digunakan untuk memposisikan elemen pada web, sekarang biasanya digunakan untuk gambar.)
16) Positioning (Positioning memungkinkan kita meletakkan posisi elemen di tempat yang tidak sesuai dengan Normal Flow. Terdapat beberapa attribute didalamnya, seperti attribute position yang digunakan untuk mengubah posisi elemen, dan pada attribute position memiliki beberapa value seperti relative yang merupakan posisi yang serupa dengan static positioning, yang dimana element akan ditempatkan sesuai Normal Flow. Namun setelah ditempatkan, kita dapat mengubah posisi elemen. Lalu ada value absolute yang merupakan menghapus elemen dari Normal Flow, bahkan tidak terdapat space yang digunakan sama sekali. Selanjutnya, terdapat attribute z-index yang digunakan untuk mengubah posisi tumpukan element yang tercampur pada position Static (defaultnya), Relative dan Absolute. Lalu terdapat value fixed pada attribute position, yang merupakan menghapus elemen dari Normal Flow, bahkan tidak terdapat space yang digunakan sama sekali, jadi serupa dengan Absolute Positioning, yang membedakannya adalah pada Absolute Position ketika di scroll maka elementnya akan mengikuti karena Absolute Position itu parentnya merupakan HTML, sedangkan pada Fixed Position ketika di scroll maka elementnya akan diam ditempat karena parentnya merupakan viewport. Lalu ada juga value sticky pada attribute position yang merupakan gabungan dari antara relative dan fixed position, sesuai untuk menampilkan fitur menu pada halaman HTML.)
17) Fraction (Fraction merupakan satuan unit sisa ruang dalam Grid, sisa ruang biasanya adalah sisa ruang yang bisa diisi setelah di kurangan Grid Item yang tidak flexible (ukurannya sudah fix).)
18) Media Queries (Digunakan untuk memodifikasi tampilan web sesuai dengan kondisi Device, Web Browser, atau System Setting milik pengguna. Terdapat 2 cara untuk menggunakan Media Queries, bisa melalui file HTML langsung, atau bisa melalui file CSS. Pada file CSS, At-rule @media memiliki aturan penulisan seperti berikut: @media MediaType Operator MediaFeature Operator MediaFeature.)
19) Display None (membahas mengenai kegunaan attribute display yang memiliki value none (dihapus / dihilangkan).)
