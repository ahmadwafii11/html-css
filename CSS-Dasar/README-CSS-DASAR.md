Learn CSS-Dasar
1) Pengenalan CSS
2) Menambahkan CSS ke HTML (Terdapat 3 cara, yakni cara internal, eksternal dan inline)
3) Comment (/* */) (Membuat komentar di CSS)
4) ID (#) - (Membuat id di CSS)
5) Class dan Multiple Class (.) - (Membuat class di CSS, berguna untuk mempermudah style di beberapa bagian tag pada HTML)
6) Selector - (Teradapat beberapa jenis selector seperti id selector (#), class selector(.), selector list(,))
7) Combinator Selector (terdapat 4 jenis selector yakni descendant selector (space), child selector (>), adjacent sibling selector (+) dan general sibling selector (~))
8) Attribute Selector (Banyak macam attribute selector didalamnya)
9) Color (CSS untuk color dengan cara color name, Hex Code, RGB maupun HSL)
10) Text (Banyak sekali properti atau format untuk merubah text seperti text-align, text-decoration, text-spacing, text-shadow, text-transformation,dll.)
11) Font (Terdapat banyak sekali properti atau format untuk mengubah font pada teks seperti font-family, font-size, font-stretch, font-style, font-variant, font-weight, dll)
12) Background (Menggunakan properties backgound untuk merubah backgorund / latar belakang dari tiap element di HTML, contohnya seperti background-color)
13) Box Model (Menggunakan properties seperti padding, margin, dan border. secara berurutan dimulai dari content (isi konten) - padding (jarak dari content ke border) - border (batas garis isi content & padding dengan margin (ditandai dengan garis putus-putus atau lurus tebal) - margin (jarak antar suatu tag HTML satu dengan tag HTML lainnya). Catatan: ketika margin (area terluar dari content) antar tag saling bertemu, diambil margin tertinggi dari suatu tag tersebut. Kenapa? karena margin merupakan area terluar dan transparan sehingga tidak terisi oleh background apapun.)
14) Debug dengan Browser (Debug untuk melihat informasi mengenai halaman HTML beserta CSSnya sehingga akan mendapatkan informasi seperti content-padding-border-margin dari tiap tag HTML yang kita pilih dengan inspect Chrome / Web Browser bagian elements)
15) Min dan Max Size (Mengatur minimal dan maksimal size untuk element HTML dapat menggunakan properties min-height (minimal tinggi) & min-width (minimal lebar) serta max-height (maksimal tinggi) & max-width (maksimal lebar))
16) Border (Mengatur garis tepi pada kontent dan padding sebelum menuju ke area luar content, yakni margin. Terdapat beberapa properties seperti border-style, border-width, untuk lebih detailnya seperti border-right, border-left, border-top, border-bottom, serta properties border-radius.)
17) Outline (Serupa dengan border, namun yang membedakan adalah pada Outline tidak mengambil space dari Box Model, sedangkan pada Border akan mengambil space dari Box Model. Selain itu, letak Outline berada setelah Border. Untuk properties, kira-kira sama seperti Border.)
18) Background Image (Menggunakan properties background-image untuk membuat backgorund dengan latar belakang gambar. Serta penggunaan properties backgorund-image: linear-gradient untuk background warna gradient.)
19) Opacity (Menggunakan properties opacity untuk mengatur transparansi element di HTML)
20) Value dan Units (Value dan unit dalam CSS seperti px, pt, cm em, mm, dll. Untuk selengkapnya dapat dilihat pada link berikut https://developer.mozilla.org/en-US/docs/Web/CSS/length)
21) Writing Mode (Menggunakan properties writing-mode untuk membaringkan teks, apakah ingin horizontal atau vertikal)
22) Overflow (Menggunakan properties overflow untuk mengatasi isi konten yang melebihi dari Box Model. Kita dapat menggunakan value seperti auto (yang dimana langsung auto terdapat scrollnya) atau hidden (isi konten yang melebihi box model akan dihilangkan))
23) Pseudo-element Selector (merupakan kata kunci untuk menambah selector ke bagian tertentu dari element yang terseleksi. Biasanya ditandai dengan pemisah :: (titik dua sebanyak 2 kali))
24) Pseudo-classes Selector (merupakan kata kunci yang ditambahkan ke selector yang merepresentasikan state / keadaan tertentu dari element yang diseleksi. Untuk menambahkan pseudo-classes, kita dapat menggunakan : (titik dua).)
25) Link (Mneggunakan properti link dengan campuran pseudo-classes seperti a:hover & a:visited untuk mengubah tampilan pada tag a HTML link)
26) List (Menggunakan properties seperti list-style-type & list-style-position untuk mengubah tag list pada HTML.)
27) Table (Menggunakan properties seperti border-collapse, border-style, border-width, width, height & text-align untuk mengatur style pada table.)
28) Form (Menggunakan beberapa properties seperti border-style, border-color, border-radius serta penggunaan pseudo-classes seperti input:required, #username:focus, #password:focus, #login:hover untuk style form HTML)
29) Content (Menggunakan properties seperti content serta pseudo-elements seperti .konten::after & .konten::before untuk merubah isi dari konten.)
30) Counter (Menggunakan properties seperti counter-set untuk membuat counter, counter-increment untuk menaikkan counter, counter-reset untuk melakukan reset counter, serta menggunakan function counter() untuk mengambil nilai counter.)
31) Filter (Menggunakan properties filter dengan beberapa value salah satunya adalah blur untuk meningkatkan efek blur pada gambar maupun paragraf.)
32) Import (Menggunakan @import url() untuk menggantikan tag link agar dapat tersambung ke file eksterna CSS pada file HTML.)
33) Cascade (Cascade merupakan logika bagaimana web browser mengumpulkan properties CSS dari beberapa sumber sebelum ditampilkan. Terdapat tiga sumber yakni User Agent (Default bawaan browser), Author Stylesheet (Author CSS dari library semacam Bootstrap & Tailwind CSS), dan User Stylesheet (Kita sendiri yang desain di file CSS). Nah, jika dari beberapa sumber tadi membuat sebuah aturan CSS yang sama, maka urutan posisi yang paling akhir yang akan digunakan oleh Web Browser (Urutannya : User Agent Stylesheet --> Author Stylesheet --> User Stylesheet). Selain itu, !important untuk membuat atau mengubah suatuh aturan menjadi sangat penting, sehingga tidak dapat dirubah aturan tersebut dengan aturan lain di CSS.)
34) Layer (Alternatif lain dari !important yakni @layer (seperti tumpukan kayak layer adobe), yang dimana kita dapat menentukan layer mana yang berada di posisi penting.)
